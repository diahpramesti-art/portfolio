# 🌐 Diah Pramesti — Portfolio & Credentials System

Modern, responsive web portfolio built with custom UI design and dynamic Google Sheets API integration to showcase academic credentials, technical skills, and professional works.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, Modern CSS3 (CSS Variables, Glassmorphism UI), JavaScript (ES6+)
- **Database & Data Pipeline:** Google Sheets API (CSV Published Endpoint)
- **Analytics & Tracking:** Google Analytics 4 (`gtag.js`)
- **Icons & Typography:** FontAwesome v6, Google Fonts (Syne & Plus Jakarta Sans)

---

## ✨ Core Features

- **Dynamic Data Sync:** Automatically fetches experience and credential records from a structured spreadsheet database.
- **Interactive Search & Filter:** Quick real-time filtering by project category and keywords.
- **Modal Quick View:** Enables seamless document previews without page reloads.
- **Request Resume System:** Direct email trigger integration for CV requests.
